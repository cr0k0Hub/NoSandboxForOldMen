# NoSandboxForOldMen

Инструмент для детекта виртуальных сред и отладки. Предназначен для образовательных целей.

## ⚠️ Дисклеймер

Этот инструмент создан для образовательных целей и для использования в легитимных пентестах. Автор не несёт ответственности за применение в зловредных кампаниях.

## 🎯 Что он делает

`NoSandboxForOldMen` проверяет окружение, в котором запущен, и сообщает, является ли оно:
- Виртуальной машиной (VirtualBox, в будущем — VMware, QEMU, Hyper-V)
- Средой с активным отладчиком

Если инструмент находит признаки подделки — он возвращает `TRUE`. Если среда чиста — `FALSE`.

## 📦 Текущие проверки

| Тип проверки | Статус | Описание |
|:---|:---|:---|
| **VirtualBox: Реестр** | ✅ Реализовано | Поиск ключей `HKLM\SOFTWARE\Oracle\VirtualBox Guest Additions` и служб VBox в `CurrentControlSet\Services` |
| **VirtualBox: Файлы** | ✅ Реализовано | Поиск драйверов и библиотек VirtualBox в `System32` и `drivers` |
| **VirtualBox: Службы** | 🔧 В разработке | Проверка запущенных служб (`VBoxService`, `VBoxGuest` и др.) через SCM |
| **VirtualBox: Процессы** | 🔧 В разработке | Поиск процессов `VBoxTray.exe`, `VBoxService.exe` |
| **Отладка: PEB** | ✅ Реализовано | Проверка флага `BeingDebugged` через прямое чтение PEB (`__readgsqword(0x60)`) |
| **Отладка: IsDebuggerPresent** | ✅ Реализовано | Классическая проверка WinAPI (для проформы) |
| **Гипервизор: CPUID** | 🔧 В разработке | Проверка наличия гипервизора через инструкцию `cpuid` с листом `0x40000000` |

## 🧱 Архитектура

Проект построен модульно. Каждый тип проверки вынесен в отдельную пару `.h`/`.c`, что позволяет легко добавлять новые цели (VMware, QEMU, Hyper-V) без модификации ядра.
```
NoSandboxForOldMen/
├── AntiDebug.h / .c     # Главный модуль, точка входа AntiDebug()
├── VirtBox.h / .c       # Сигнатуры и проверки для VirtualBox
├── Reg.h / .c           # Обёртка для проверки ключей реестра
├── Files.h / .c         # Обёртка для работы с файлами
├── nt_utils.h           # Низкоуровневые определения (PEB и т.д.)
└── NoSandboxForOldMen.c # Точка входа для тестирования
```
